# NextFarm tap

Homebrew formula and Scoop manifest for the NextFarm command-line tool.

```bash
brew install nextx-organization/nextfarm/nextfarm
```

```powershell
scoop bucket add nextfarm https://github.com/nextx-organization/homebrew-nextfarm
scoop install nextfarm/nextfarm
```

The formula is updated automatically on every release. Docs: https://developers.nextfarm.vn/docs/cli
